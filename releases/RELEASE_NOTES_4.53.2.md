**QWebMap 4.53.2**

QWebMap started as a fork of [GallPeters/QGIS2VectorTiles](https://github.com/GallPeters/QGIS2VectorTiles) by Jossef Kanter. It is not an official release of the original plugin, and it installs next to it.

This is the **generic** edition — the one to download. (A special Hungarian zoning-plan edition, not for general use, is released separately with a `-hu` tag.)

### Changed
- **No "Views" heading on the web map.** With several views, the view buttons (or the drop-down when they do not fit) no longer have a *Views* heading beside them: it only took room, and the buttons turned into the drop-down sooner. Screen readers still announce the bar as *Views*.

Re-export the map to get the change (the web map code is part of each release).
